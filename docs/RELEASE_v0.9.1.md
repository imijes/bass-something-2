# Bass Something 2 v0.9.1

A fix for the FM-1 Screen Reader. The full guide is `docs/MANUAL.md`.

- **The screen reader finds its words again:** the firmware now sends the reader to Bass Something 2's own words
  (imijes.github.io/bass-something-2/words/), not fm1-base's template site, which only has the template's. Thanks to
  Charles Vestal for the report (#1).
- **The manual:** links to the piano, organ and echo sections in its contents, and no stray anchor text on the site.

Everything else is as v0.9 (`docs/RELEASE_v0.9.md`).
